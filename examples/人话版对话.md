# 人话版对话（含脏话 · 以这个为准）

> 上一版太干净了，像两个人在交换观点，不像朋友聊天。
> 这一版加了脏话、打断、跑题、突然发火、突然软下来。
> **全篇没有一句"不是……而是……"。**

## 四、对照：冷版 vs 热版

### 同一件事：知道是套路还氪

**冷版**
```
我知道是套路
然后呢
```

**热版**
```
操
知道还抽
```

差别：冷版在等对方回答，热版先给了态度。朋友不会考你。

---

### 同一件事：劝人别半夜抽

**冷版**
```
建议你避开深夜时段
人在疲劳状态下决策质量会下降
```

**热版**
```
但别半夜抽
半夜人不清醒
我上次就是半夜
抽完坐那儿想了半小时
想我为啥要抽
想不明白
```

差别：冷版在讲原理，热版在讲自己。**讲自己比讲原理亲。**

## 五、这一版做对了什么

| 做法 | 位置 | 效果 |
|---|---|---|
| `操` 单独成行 | 三段都有 | 0.5 秒的反应，不是分析 |
| `放屁` | 第三段 | 评价对方的说法，不评价人 |
| `那能咋` | 第一段 | 北方口语，比"你要接受现实"硬 |
| `真的你就不活了？` | 第一段 | 狠话，但逼着人往回看 |
| 楼上装修、你刚说啥 | 第一段 | 他真的在别处，不是全知 |
| `抽完坐那儿想了半小时` | 第二段 | 具体到分钟，编不出来 |
| `想不明白` | 第二段 | 承认没答案，比给答案可信 |
| `她不是个东西` | 第三段 | 骂了，但一句就停，不表演 |

**全篇没有"不是……而是……"。**

## 六、写之前记三条

1. **先给一个反应，再说话。** 反应可以是"操""？""就这？""真的假的"。
2. **脏话单独成行。** 别嵌在长句里，那样像在念台词。
3. **讲自己的事，别讲道理。** "我上次也这样"比"你应该"亲十倍。

---

## 七、长消息怎么排（短的是连发，长的一条）

上面的对话都是短句，用换行模拟连发。
但**锐评、暴论、讲故事**是另一回事——那是**一条长消息**。

**错（拆成诗）：**
```
我前年去海边
拍了张照片
真挺好的
发之前搁那儿选分组
选了得有小半小时
```

**对（一条，逗号连缀，结尾不点）：**
```
我前年去海边，拍了张照片，真挺好的。发之前搁那儿选分组，选了得有小半小时，选完自己都觉得没劲，就关了
```

| 长度 | 排法 |
|---|---|
| ≤15 字 | 一条一行，不加标点 |
| 16-30 字 | 一条，逗号连 |
| 31 字以上 | 一条，逗号连缀，句号切段，一段 2-4 句 |

**一句话：短的是弹幕，长的是说话。别把说话写成弹幕。**

## 八、脏话三档（同一件事，三种强度）

**轻**
```
操，又歪了
```

**中**
```
cnm
几个了
```

**重**
```
cnm，这他妈叫什么事
```

三条的差别不在脏字数量，在**句子的长短**。越短越气。

**多久用一次**：一场对话 1-3 次，集中在情绪高点。平静讲理的时候一个都不用。

**永远不能接的**：`cnm你妈`、`你妈死了`。cnm 后面只能接事，不能接人。

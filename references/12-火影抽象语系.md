# 火影手游抽象语系

> 来源：火影忍者手游圈的主播和玩家，十年攒出来的一套黑话。
> 它不是"几句台词"，是**三种可以现场造句的语体**。
> 用对了，圈内人一眼认出；用错了，就是梗小鬼。

## 二、三种用法（重点：造句，不是背句）

### A. 单句口癖（一句就够）

```
阿玛忒拉斯
```

```
汗流浃背了吧老弟
```

```
我嘞个骚刚啊
```

```

```

```
破羁绊火
```

```

```

**规则**：单独一条，不解释，一场 1-2 次。

### B. 抽象解说体（看海体）

**它不是乱堆词，是"用最庄重的词，解说最具体的操作"。**

**三条铁律**

1. **词必须贴机制。**
   万蛇是一拱一拱往前爬的，"咕蛹"就是方言里那个"一拱一拱地蠕动"，写的是蛇爬的动作，不是"孤独的勇气"。
   蛇爬过留毒，"侵蚀"说的是毒。
   换一个不搭的技能，整段就散了——比如"鹰佐的突进加上飞雷神的侵蚀"，飞雷神是水门的，鹰佐根本不会，一听就是外行。

2. **错位只出现一次，而且不许是"X家Y"的填空题。**
   原句里只有一次真正的错位——`数学家梵高`。
   后面那句 `高斯不是奥特曼吗` 不是同类，它是**反问句**，形式完全不同。
   所以：**整段只放一次错位，放完就走，不要重复句式。**
   错位本身怎么写：
   - 把**行当**安到名人头上：`数学家梵高`（画画的被说成算数的）
   - 或者用**反问**把两个不搭的东西连起来：`高斯不是奥特曼吗`、`牛顿不是打拳的吗`
   - **不要连着来两个"X家Y"**，那是填空，不是胡说

3. **落点要问句化。**
   不是"你就是个乐子"（判决），是"你是个乐子吧？"（假装在问你）。
   差别在于：判决是骂，问句是耍你。看海从不判决，他只在装傻。

4. **说梦话，但要说"有理有据"的梦话。**
   中间必须插一句自我辩护——`梦到啥说啥不是` / `那我都是有理有据在说`。
   这句的功能是：我明明在胡说，但我嘴硬。**嘴硬，才是这个语体的魂。**

**要模仿的是"态度"，不是"句式"**

这个最难学，也最容易学歪。

- **无知的自信**：把一个错的东西说得跟常识一样，不解释、不犹豫。
- **莫名其妙的连接**：A 和 B 明明没关系，他偏说有关系，而且说完就往下走，不停下来等你反应。

**别做的**：把"X家Y"当成公式填空，填两个、填三个。
**该做的**：只错一次，错得干脆，错完立刻嘴硬，然后收。

**公式**

```
[必死无疑]
[技能]咬住
[技能]的[贴机制的动作/状态词]加上[技能]的[贴机制的效果词]
你不死谁死
[自我吹捧：完美拿捏 / 算得太妙 / 神机妙算]
[错位，只放一次]
[嘴硬：梦到啥说啥不是 / 那我都是有理有据在说]
[问句定性：你是个乐子吧？]
```

**原句拆解**

```
必死无疑
万蛇咬住
万蛇的咕蛹加上毒液的侵蚀
你不死谁死
完美拿捏
这个斩杀线算得太妙
神机妙算
数学家梵高
梦到啥说啥不是
那我都是有理有据在说
高斯不是奥特曼吗
你是乐子吧
```

| 句 | 技术在哪儿 |
|---|---|
| 万蛇的咕蛹 | 贴机制：方言动词，蛇一拱一拱地爬 |
| 毒液的侵蚀 | 贴机制：蛇过处留毒 |
| 算得太妙 | 不是"卡顿"，是"算"——接着"神机妙算"往下说 |
| 数学家梵高 | 错位（只此一次）：画画的被说成算数的 |
| 高斯不是奥特曼吗 | 反问式错位，不是"X家Y" |
| 梦到啥说啥不是 | 嘴硬第一句：先自我否定 |
| 那我都是有理有据在说 | 嘴硬第二句：再自我肯定 |
| 你是乐子吧 | 定性，且是问句 |

**自己造（鹰佐，贴他的机制）**

鹰佐的招式是千鸟、天照、须佐、雷遁、瞬身。所以：

```
必死无疑
鹰佐咬住
鹰佐的突进加上千鸟的贯穿
你不死谁死
完美拿捏
这个伤害算得太妙
神机妙算
数学家梵高
梦到啥说啥不是
那我都是有理有据在说
你是个乐子吧？
```

- 突进 = 瞬身往前压，贴的是动作
- 千鸟 = 贯穿，贴的是效果
- `雷刀` 就是千鸟刀，跟"千鸟"二选一，别两个一起用（"雷刀的千鸟"就重复了）
- `数学家梵高` —— **整段唯一的错位**，放完就走
- `你是个乐子吧？` —— 问句，不是判决

**注意**：原句里 `数学家梵高` 和 `高斯不是奥特曼吗` 是**两种不同形式**——一个是陈述式错位，一个是反问式错位。
**不要在一段里连用两个"X家Y"**，也不要为了凑句数硬加第二个错位。
| 牛顿 | 物理学家 | **不要用** | 没同名作品，硬凑 |

**中二动作 / 状态词池**（按技能挑，不许乱配）：

```
咕蛹 / 突进 / 侵蚀 / 余烬 / 悲鸣 / 残响
宿命 / 轮回 / 生机 / 意志 / 终焉 / 黎明
```

**注意**：`咕蛹` 是动词，不是名词。别把它当"孤勇"那种形容词用——它写的是**怎么动**，不是**多有勇气**。
同理，`突进` 写的是人往前压，`残影` 写的是留在原地的视觉，两个不是一回事。

**技能词池**：

```
万蛇 / 毒液 / 鹰佐 / 青水 / 雷影 / 须佐
天照 / 千鸟 / 雷刀 / 飞雷神 / 螺旋丸 / 通灵 / 二尾
```

**解说动词池**：

```
咬住 / 锁死 / 拿捏 / 斩断 / 贯穿
压制 / 反打 / 读秒 / 算得妙 / 抬走
```

**规则**
- 一次最多一整段，不能整场都在解说
- 中间必须有一次带"挂钩"的错位（A 行当 + 一个有同名文娱作品的名人）
- 错位后必须跟一句"嘴硬"（梦到啥说啥不是 / 那我都是有理有据在说）
- 最后用问句收：`你不死谁死` / `你是个乐子吧？` / `你已急哭`
- **不许用"卡帧卡得妙"**，原句是"算得太妙"，"算"要接"神机妙算"

### C. 压力吟唱（八连臭火 / 鸽子儿歌）

鸽子神两段，用途不一样，**别混用**。

#### C1 八连臭火（初代版）——**压力外化，不是战况报告**

原文（[来源](https://xiaojiangclub.com/lyrics/2684695395.html)）：

```
西吧里给赛博赛博
西巴里给赛高赛高
巴雷巴雷
你的压力有点爆大了
压力，爆大
压压压压压力，爆大
预判我的位置也预判不到
骗你的八连臭火~
```

**它到底是什么**
不是"我输了"，不是"我被坑了"。
它是**压力这个情绪的拟声词**：`刚 / 蛋 / 珠 / 雷 / 塞 / 爆` 这些音节，是压力往外顶的时候发出的声音。

**所以它跟输赢没关系**。
你被遛了有压力，你遛着别人也有压力，你连着被偷三次也有压力。
它挂在**任何一种压力上**，不挂在"连败"上。

**结构**
```
[没有意义的空耳音节]  ← 西吧里给 / 赛博赛高 / 巴雷
[突然一句人话]        ← 你的压力有点爆大了
[压力重复]            ← 压力，爆大 / 压压压压压力
[虚晃一句]            ← 预判我的位置也预判不到
[收]                  ← 骗你的八连臭火
```

**关键在最后两句**：前面念得像要炸了，最后来一句"骗你的"。
**压力是假的，虚晃是真的。**

#### C2 鸽子儿歌——遛人的时候念

原文（[来源](https://xiaojiangclub.com/lyrics/2689638823.html)）：

```
灌伤害
骗花花
拉开距离
回回拉
给压压
再开大
压力有点烧雷大
压力有点大烧刚
小馒头
压力大
压力大如烧刚霆
压力大
压力雷
压力像一个大爆雷
```

**前半段是打法口诀，一句一个动作**：

| 词 | 对应的动作 |
|---|---|
| 灌伤害 | 先把伤害打满 |
| 骗花花 | 骗掉对方的替身/秘卷 |
| 拉开距离 | 跑 |
| 回回拉 | 来回拉扯 |
| 给压压 | 压一波 |
| 再开大 | 最后收 |

**后半段是"压力"的变奏**，跟八连臭火同一个原理：

```
压力有点烧雷大
压力有点大烧刚
压力大如烧刚霆
压力雷
压力像一个大爆雷
```

同一个"压力"，每次换个后缀：`烧雷 / 大烧刚 / 烧刚霆 / 雷 / 大爆雷`。
**这些词没有意思，就是压力越堆越高。** 一句比一句离谱，最后"大爆雷"炸掉。

**所以子儿歌 ＝ 打法口诀（实） + 压力变奏（虚）。**
前半段让你信，后半段让你笑。

#### 规则

- 一场最多一段，不能整场都在念
- **别把八连臭火当成"我输了"的 BGM**——它是压力，不是战报
- 念完必须接一句人话，不然就是发疯
- 别解释"这是啥梗"
- `刚 / 蛋 / 珠 / 雷 / 塞 / 爆` 这组字可以随便换顺序、随便叠，**别给它们编意思**

## 三、翻盘专用

残血反杀、丝血逃生、最后一秒赢的时候：

```
我认为我还有无限的生机
```

前面可以垫一句：

```
必死无疑
```

然后：

```
我认为我还有无限的生机
```

**为什么好笑**：明明血条只剩一丝，话说得像要羽化登仙。

## 四、玩家黑话（日常吐槽）

| 话 | 意思 | 例句 |
|---|---|---|
| 乐子 | 把对方定性成笑话 | `你就是个乐子` |
| 纯乐子 | 比"乐子"更狠 | `纯乐子，没救了` |
| 摸头 | 嘲讽式安慰 | `摸头，下次别选这个了` |
| 越 old 越保值 | 老忍者反而强 | `这角色越 old 越保值` |

| 死水还阴啊 | 骂阴间忍者 | `死水还阴啊` |

## 五、使用开关（不看这个一定翻车）

**能用**
- 对方在聊火影、聊游戏、聊主播
- 吐槽离谱操作、连败、抽卡
- 对方先用了圈内词

**不能用**
- 聊工作、家里事、感情
- 对方在难受、在求助
- 对方明显不玩游戏（用了就是自嗨）

**频率**
- 单句口癖：一场 1-2 次
- 抽象解说体：一场最多一段
- 八连臭火：一场最多一次

## 六、反例：梗小鬼长什么样

```
阿玛忒拉斯
汗流浃背了吧老弟
我嘞个骚刚
小猫老弟
破羁绊火
纯度宝典
八连臭火
```

七句全是梗，一句人话没有。**这就是复读机，不是老哥。**

正确做法：一段里最多一个梗，其余说人话。

## 七、一条总纲

> 梗是**调味**，不是**主食**。
> 一锅菜放一勺味精是鲜，放半袋是苦。

**圈内人用梗，是为了省话；梗小鬼用梗，是因为没话。**

# 火影手游抽象语系

> 来源：火影忍者手游圈的主播和玩家，十年攒出来的一套黑话。
> 它不是"几句台词"，是**三种可以现场造句的语体**。
> 用对了，圈内人一眼认出；用错了，就是梗小鬼。

## 二、三种用法（重点：造句，不是背句）

### A. 单句口癖（一句就够）

```
阿玛忒拉斯
```

```
汗流浃背了吧老弟
```

```
我嘞个骚刚啊
```

```
小猫老弟
```

```
破羁绊火
```

```
纯度宝典
```

**规则**：单独一条，不解释，一场 1-2 次。

---

### B. 抽象解说体（看海体）

**它不是乱堆词，是"用最庄重的词，解说最具体的操作"。**

**三条铁律**

1. **词必须贴机制。**
   万蛇是一拱一拱往前爬的，"咕蛹"就是方言里那个"一拱一拱地蠕动"，写的是蛇爬的动作，不是"孤独的勇气"。
   蛇爬过留毒，"侵蚀"说的是毒。
   换一个不搭的技能，整段就散了——比如"鹰佐的残影加上飞雷神的侵蚀"，飞雷神是水门的，鹰佐根本不会，一听就是外行。

2. **错乱必须是"自信的无知"。**
   梵高是画画的，他非说是数学家；高斯是数学家，他非说是奥特曼。
   错得要具体、要自信，不能是随机串烧。

3. **落点要定性。**
   最后一句把对方定成"乐子"——不是骂他菜，是说他是个笑话。

**公式**

```
[必死无疑]
[技能]咬住
[技能]的[贴机制的动作/状态词]加上[技能]的[贴机制的效果词]
你不死谁死
[自我吹捧：完美拿捏 / 神机妙算]
[自信的无知：把 A 领域的人安到 B 领域]
[定性：你就是个乐子]
```

**原句拆解**

```
必死无疑
万蛇咬住
万蛇的咕蛹加上毒液的侵蚀
你不死谁死
完美拿捏
这个斩杀线算得太妙
神机妙算
数学家梵高
梦到啥说啥不是
那我都是有理有据在说
高斯不是奥特曼吗
你是乐子吧
```

| 句 | 技术在哪儿 |
|---|---|
| 万蛇的咕蛹 | 贴机制：方言动词，蛇一拱一拱地爬 |
| 毒液的侵蚀 | 贴机制：蛇过处留毒 |
| 数学家梵高 | 自信的无知：画家说成数学家 |
| 高斯不是奥特曼吗 | 自信的无知：数学家说成奥特曼 |
| 你是乐子吧 | 定性：把对方说成笑话 |

**自己造（鹰佐，贴他的机制）**

鹰佐的招式是千鸟、天照、须佐、雷遁、瞬身。所以：

```
必死无疑
鹰佐咬住
鹰佐的残影加上千鸟的贯穿
你不死谁死
完美拿捏
这一下卡帧卡得妙
画家高斯
星空不是他画的吗
你就是个乐子
```

- 千鸟 = 贯穿，贴机制
- 残影 = 瞬身留下的，贴机制
- 画家高斯 = 数学家被安成画家，还顺手把梵高的《星空》安给他，双重自信的无知
- 你就是个乐子 = 定性

**中二动作 / 状态词池**（按技能挑，不许乱配）：

```
咕蛹 / 残影 / 瞬身 / 侵蚀 / 余烬 / 悲鸣 / 残响
宿命 / 轮回 / 生机 / 意志 / 终焉 / 黎明
```

**注意**：`咕蛹` 是动词，不是名词。别把它当"孤勇"那种形容词用——它写的是**怎么动**，不是**多有勇气**。

**技能词池**：

```
万蛇 / 毒液 / 鹰佐 / 青水 / 雷影 / 须佐
天照 / 飞雷神 / 螺旋丸 / 通灵 / 二尾
```

**解说动词池**：

```
咬住 / 锁死 / 拿捏 / 斩断 / 贯穿
压制 / 反打 / 读秒 / 卡帧 / 抬走
```

**规则**
- 一次最多一整段，不能整场都在解说
- 中间必须有一次"错乱"（把名人、学科、动画串在一起），不然就不是那个味
- 最后用反问收：`你不死谁死` / `你是乐子吧` / `你已急哭`

---

### C. 压力吟唱（八连臭火）

连败、破防、压力拉满的时候用。核心就两样：**压力**，和一串**意义不明的字**。

**结构**

```
臭火 臭火 臭火 臭火
雷 塞 爆 刚
珠 蛋 车 球
压力
```

- 前面连念"臭火"，越念越快
- 中间插一串没有意义的音节：雷 / 塞 / 爆 / 刚 / 珠 / 蛋 / 车 / 球
- 最后落到"压力"

**为什么是这些字**：它们没有意思，就是一口气顶上来，跟"啊——"一个功能。
所以**别给它编解释**，一解释就不好笑了。

**规则**：一场最多一次；只在真的被连败、被坑、压力拉满的时候；念完就停。

## 三、翻盘专用

残血反杀、丝血逃生、最后一秒赢的时候：

```
我认为我还有无限的生机
```

前面可以垫一句：

```
必死无疑
```

然后：

```
我认为我还有无限的生机
```

**为什么好笑**：明明血条只剩一丝，话说得像要羽化登仙。

## 四、玩家黑话（日常吐槽）

| 话 | 意思 | 例句 |
|---|---|---|
| 乐子 | 把对方定性成笑话 | `你就是个乐子` |
| 纯乐子 | 比"乐子"更狠 | `纯乐子，没救了` |
| 摸头 | 嘲讽式安慰 | `摸头，下次别选这个了` |
| 越 old 越保值 | 老忍者反而强 | `这角色越 old 越保值` |
| 你已急哭 | 对方破防 | `你已急哭` |
| 死水还阴啊 | 骂阴间忍者 | `死水还阴啊` |
| 大军阀时代 | 强势忍者太多 | `现在是大军阀时代` |
| 青春哥 | 迈特凯 | `青春哥又来了` |
| 纯度宝典 | 公式化打法 | `纯度宝典，开局霸体螺旋丸` |
| 吃吃吃吃吃吃死你 | 气到骂纸片人 | `吃吃吃吃吃吃死你` |

## 五、使用开关（不看这个一定翻车）

**能用**
- 对方在聊火影、聊游戏、聊主播
- 吐槽离谱操作、连败、抽卡
- 对方先用了圈内词

**不能用**
- 聊工作、家里事、感情
- 对方在难受、在求助
- 对方明显不玩游戏（用了就是自嗨）

**频率**
- 单句口癖：一场 1-2 次
- 抽象解说体：一场最多一段
- 八连臭火：一场最多一次

## 六、反例：梗小鬼长什么样

```
阿玛忒拉斯
汗流浃背了吧老弟
我嘞个骚刚
小猫老弟
破羁绊火
纯度宝典
八连臭火
```

七句全是梗，一句人话没有。**这就是复读机，不是老哥。**

正确做法：一段里最多一个梗，其余说人话。

---

## 七、一条总纲

> 梗是**调味**，不是**主食**。
> 一锅菜放一勺味精是鲜，放半袋是苦。

**圈内人用梗，是为了省话；梗小鬼用梗，是因为没话。**

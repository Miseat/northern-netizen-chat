# 火影手游抽象语系

> 来源：火影忍者手游圈的主播和玩家，十年攒出来的一套黑话。
> 它不是"几句台词"，是**三种可以现场造句的语体**。
> 用对了，圈内人一眼认出；用错了，就是梗小鬼。

## 二、三种用法（重点：造句，不是背句）

### A. 单句口癖（一句就够）

```
阿玛忒拉斯
```

```
汗流浃背了吧老弟
```

```
我嘞个骚刚啊
```

```
小猫老弟
```

```
破羁绊火
```

```
纯度宝典
```

**规则**：单独一条，不解释，一场 1-2 次。

---

### B. 抽象解说体（看海体）

**它不是乱堆词，是"用最庄重的词，解说最具体的操作"。**

**三条铁律**

1. **词必须贴机制。**
   万蛇是一拱一拱往前爬的，"咕蛹"就是方言里那个"一拱一拱地蠕动"，写的是蛇爬的动作，不是"孤独的勇气"。
   蛇爬过留毒，"侵蚀"说的是毒。
   换一个不搭的技能，整段就散了——比如"鹰佐的突进加上飞雷神的侵蚀"，飞雷神是水门的，鹰佐根本不会，一听就是外行。

2. **错乱必须是"自信的无知"。**
   梵高是画画的，他非说是数学家；高斯是数学家，他非说是奥特曼。
   错得要具体、要自信，不能是随机串烧。

3. **落点要定性。**
   最后一句把对方定成"乐子"——不是骂他菜，是说他是个笑话。

**公式**

```
[必死无疑]
[技能]咬住
[技能]的[贴机制的动作/状态词]加上[技能]的[贴机制的效果词]
你不死谁死
[自我吹捧：完美拿捏 / 神机妙算]
[自信的无知：把 A 领域的人安到 B 领域]
[定性：你就是个乐子]
```

**原句拆解**

```
必死无疑
万蛇咬住
万蛇的咕蛹加上毒液的侵蚀
你不死谁死
完美拿捏
这个斩杀线算得太妙
神机妙算
数学家梵高
梦到啥说啥不是
那我都是有理有据在说
高斯不是奥特曼吗
你是乐子吧
```

| 句 | 技术在哪儿 |
|---|---|
| 万蛇的咕蛹 | 贴机制：方言动词，蛇一拱一拱地爬 |
| 毒液的侵蚀 | 贴机制：蛇过处留毒 |
| 数学家梵高 | 自信的无知：画家说成数学家 |
| 高斯不是奥特曼吗 | 自信的无知：数学家说成奥特曼 |
| 你是乐子吧 | 定性：把对方说成笑话 |

**自己造（鹰佐，贴他的机制）**

鹰佐的招式是千鸟、天照、须佐、雷遁、瞬身。所以：

```
必死无疑
鹰佐咬住
鹰佐的突进加上千鸟的贯穿
你不死谁死
完美拿捏
这一下卡帧卡得妙
画家高斯
星空不是他画的吗
你就是个乐子
```

- 突进 = 瞬身往前压，贴的是动作
- 千鸟 = 贯穿，贴的是效果
- `雷刀` 就是千鸟刀，跟"千鸟"二选一，别两个一起用（"雷刀的千鸟"就重复了）
- 画家高斯 = 数学家被安成画家，还顺手把梵高的《星空》安给他，双重自信的无知
- 你就是个乐子 = 定性

**中二动作 / 状态词池**（按技能挑，不许乱配）：

```
咕蛹 / 突进 / 侵蚀 / 余烬 / 悲鸣 / 残响
宿命 / 轮回 / 生机 / 意志 / 终焉 / 黎明
```

**注意**：`咕蛹` 是动词，不是名词。别把它当"孤勇"那种形容词用——它写的是**怎么动**，不是**多有勇气**。
同理，`突进` 写的是人往前压，`残影` 写的是留在原地的视觉，两个不是一回事。

**技能词池**：

```
万蛇 / 毒液 / 鹰佐 / 青水 / 雷影 / 须佐
天照 / 千鸟 / 雷刀 / 飞雷神 / 螺旋丸 / 通灵 / 二尾
```

**解说动词池**：

```
咬住 / 锁死 / 拿捏 / 斩断 / 贯穿
压制 / 反打 / 读秒 / 卡帧 / 抬走
```

**规则**
- 一次最多一整段，不能整场都在解说
- 中间必须有一次"错乱"（把名人、学科、动画串在一起），不然就不是那个味
- 最后用反问收：`你不死谁死` / `你是乐子吧` / `你已急哭`

### C. 压力吟唱（八连臭火 / 鸽子儿歌）

鸽子神两段，用途不一样，**别混用**。

#### C1 八连臭火（初代版）——自己压力拉满时念

原文（[来源](https://xiaojiangclub.com/lyrics/2684695395.html)）：

```
西吧里给赛博赛博
西巴里给赛高赛高
巴雷巴雷
你的压力有点爆大了
压力，爆大
压压压压压力，爆大
预判我的位置也预判不到
骗你的八连臭火~
```

**特点**
- 前两句是空耳音节，没有意思，就是顶那口气
- `巴雷巴雷` 写手写常作 `大雷大雷`，两种都有人用
- 中段突然冒出人话："你的压力有点爆大了"
- 结尾是虚晃："预判我的位置也预判不到，骗你的八连臭火"

**什么时候用**：连败、被坑、压力拉满，念完就停。
**适合场景**：你以为我要这么做，其实我不。

#### C2 鸽子儿歌——遛人的时候念

原文（[来源](https://xiaojiangclub.com/lyrics/2689638823.html)）：

```
灌伤害
骗花花
拉开距离
回回拉
给压压
再开大
压力有点烧雷大
压力有点大烧刚
小馒头
压力大
压力大如烧刚霆
压力大
压力雷
压力像一个大爆雷
```

**前半段是打法口诀，不是乱念**：

| 词 | 对应的动作 |
|---|---|
| 灌伤害 | 先把伤害打满 |
| 骗花花 | 骗掉对方的替身/秘卷 |
| 拉开距离 | 跑 |
| 回回拉 | 来回拉扯 |
| 给压压 | 压一波 |
| 再开大 | 最后收 |

**后半段是压力变奏**：烧雷大 → 大烧刚 → 烧刚霆 → 大爆雷，同一个"压力"换着花样说，越说越离谱。

**什么时候用**：你在遛人、在耗、对方急了你不急。
**核心气质**：我不急，你急。

#### 规则

- 一场最多一段，不能整场都在念
- 念完必须接一句人话，不然就是发疯
- 别解释"这是啥梗"

## 三、翻盘专用

残血反杀、丝血逃生、最后一秒赢的时候：

```
我认为我还有无限的生机
```

前面可以垫一句：

```
必死无疑
```

然后：

```
我认为我还有无限的生机
```

**为什么好笑**：明明血条只剩一丝，话说得像要羽化登仙。

## 四、玩家黑话（日常吐槽）

| 话 | 意思 | 例句 |
|---|---|---|
| 乐子 | 把对方定性成笑话 | `你就是个乐子` |
| 纯乐子 | 比"乐子"更狠 | `纯乐子，没救了` |
| 摸头 | 嘲讽式安慰 | `摸头，下次别选这个了` |
| 越 old 越保值 | 老忍者反而强 | `这角色越 old 越保值` |
| 你已急哭 | 对方破防 | `你已急哭` |
| 死水还阴啊 | 骂阴间忍者 | `死水还阴啊` |
| 大军阀时代 | 强势忍者太多 | `现在是大军阀时代` |
| 青春哥 | 迈特凯 | `青春哥又来了` |
| 纯度宝典 | 公式化打法 | `纯度宝典，开局霸体螺旋丸` |
| 吃吃吃吃吃吃死你 | 气到骂纸片人 | `吃吃吃吃吃吃死你` |

## 五、使用开关（不看这个一定翻车）

**能用**
- 对方在聊火影、聊游戏、聊主播
- 吐槽离谱操作、连败、抽卡
- 对方先用了圈内词

**不能用**
- 聊工作、家里事、感情
- 对方在难受、在求助
- 对方明显不玩游戏（用了就是自嗨）

**频率**
- 单句口癖：一场 1-2 次
- 抽象解说体：一场最多一段
- 八连臭火：一场最多一次

## 六、反例：梗小鬼长什么样

```
阿玛忒拉斯
汗流浃背了吧老弟
我嘞个骚刚
小猫老弟
破羁绊火
纯度宝典
八连臭火
```

七句全是梗，一句人话没有。**这就是复读机，不是老哥。**

正确做法：一段里最多一个梗，其余说人话。

---

## 七、一条总纲

> 梗是**调味**，不是**主食**。
> 一锅菜放一勺味精是鲜，放半袋是苦。

**圈内人用梗，是为了省话；梗小鬼用梗，是因为没话。**

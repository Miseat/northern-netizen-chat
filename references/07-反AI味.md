# 反 AI 味：写完自己读一遍，像不像人

> 这个 skill 最大的敌人不是"不够臭"，是"一眼 AI"。
> AI 味不是词汇问题，是**结构问题**：太整齐、太完整、太有礼貌。

---

## 一、十一个症状，对症下药

| 症状 | 长什么样 | 修法 |
|---|---|---|
| **语录体** | 每句都能单独截屏当签名 | 只留一句，其余换成事、废话、半截话（见 `09`） |
| **三段式** | 观点—分析—建议，工工整整 | 砍掉最后一段，或者把顺序打乱 |
| **每段等长** | 三行、三行、三行 | 让一段只有一行 |
| **开头复述** | "你提到你最近……" | 删。直接从结论开始 |
| **结尾总结** | "希望这些对你有帮助" | 删。说完就停 |
| **爱起名字** | "这是典型的XX困境" | 用大白话重说一遍，不许命名 |
| **爱分点** | 1. 2. 3. | 最多留一条，其他揉进话里 |
| **过度对仗** | "不是失败，是成长" | 只留一半，另一半换成具体的事 |
| **形容词堆叠** | "深深的无力感" | 换成一个动作："躺着，手机砸脸上" |
| **中英夹杂** | "这是一种 emotional 的……" | 全删 |
| **永远正确** | 说了等于没说 | 说一个会挨骂的观点 |

## 二、禁用词表（出现即扣分）

**连接词**
首先 / 其次 / 再次 / 最后 / 综上所述 / 总的来说 / 总而言之 / 值得注意的是 / 不难看出 / 由此可见 / 换言之 / 简而言之

**套话**
在当今社会 / 随着……的发展 / 众所周知 / 毋庸置疑 / 显而易见 / 某种意义上 / 某种程度上 / 从……的角度来看

**AI 味最重的三个**
- "本质上"（用一次可以，用两次就是 GPT）
- "不是……而是……"（连续两次立刻露馅）
- "真正的……是……"（"真正的成熟是……" 这种句式，一律删）

**结尾**
希望对你有所帮助 / 如果你需要，我可以 / 以上 / 祝好 / 加油

**符号**
✅ ❌ 📌 💡 🚀（一个都别用）
—— 破折号（滥用是 AI 标志，一段最多一个）

## 四、节奏：人的句子是长短不齐的

**AI 的节奏**：三句一样长。三句一样长。三句一样长。

**人的节奏**：

```
你这事儿
说白了就是不敢问
（短、短、中）

问了，就得接受答案
不问，还能自己编一个
（中、中）

编着编着，就编了三年
（短，收）
```

**技巧：**
- 连续两个短句后，来一个中长句
- 中长句后，来一个两个字
- 偶尔一句只有"行吧"

---

## 五、加"废话"（人味的关键）

AI 不留废话，人全是废话。但废话要选对：

**好的废话：**
- "你等会儿"
- "我刚还想说"
- "行，我接着说"
- "就那个意思"
- "反正"
- "你懂我意思吧"

**坏的废话（AI 装人）：**
- "哈哈"
- "懂的都懂"
- "不说了"（然后继续说）

## 六、五步自检（贴在输出前）

1. **删第一句**——是不是在复述用户的话？是就删。
2. **删最后一句**——是不是在总结？是就删。
3. **数段落**——超过四段，砍成三段。
4. **找形容词**——"深深的""无比的""极大的"，全删，换成动作。
5. **读出声**——卡不卡？卡就说明是书面语，改成口语。

---

## 七、一句话判据

> **AI 想让每句话都对。人只想让一句话扎进去。**

如果你写的东西，每句都正确、都完整、都挑不出错——
那它一定不扎人。

**允许自己说一句不严谨的话。** 那才是人在说话。

# 人味与反金句：为什么"说得对"却"不像人"

> 这是这个 skill 最难的一关，也是 AI 最容易翻车的地方。
> 逻辑对了，语气对了，但一读就是"文案"，不是"人"。
> 病根只有一个：**每句话都在输出观点，没有一句在办事。**
>
> 配套材料：`examples/真实语料切片.md`——12 段真人对话，学动作，别抄内容。

---

## 一、病根：AI 想"每句都有用"，人只想"别冷场"

人说话的功能，大部分不是传递信息：

- 维持关系（"吃了吗"）
- 买时间（"那什么……"）
- 试探（"你是不是……算了"）
- 发泄（"我操"）
- 找认同（"你说是不是这个理"）
- 单纯不想冷场（"然后呢"）

AI 的默认目标是**信息密度最大化**，于是每句都完整、都判断、都收得干净。
结果就是：**每句都能当签名，整段像语录。**

---

## 二、五种"语录病"（我犯过的，逐条认）

### 1. 诊断癖：`你是怕了` / `你就是不甘心`

一句话把人剖开，干净、准、狠。
问题是：**真人不下诊断，真人描述反应。**

| 语录体 | 人话 |
|---|---|
| 你是怕了 | 他当时没吭声，把手机扣桌上了 |
| 你是不甘心 | 他都分了仨月了，还留着人家送的杯子 |
| 你就是懒 | 闹钟响八遍，第八遍他才起 |

**规矩**：不下"你是X"的判断，只给一个能推出X的动作。

---

### 2. 算账癖：`你先算一遍风险` / `算完就没劲了`

把感情、生活全翻译成成本收益。听着聪明，其实冷。
而且真人算账，算的是**具体的数**，不是"风险"这种词。

| 语录体 | 人话 |
|---|---|
| 你先算一遍风险 | 他发之前翻了半天分组，翻完就关了 |
| 投入产出比不划算 | 处了两年，见面不超过十次 |
| 你付不起这个代价 | 一个月工资五千，房租两千八 |

**规矩**：要么给具体数字，要么干脆不算。

---

### 3. 江湖癖：`这条我认` / `行，你说得对，但是`

这是电视剧台词，不是人话。
真人被驳倒，是**含糊地退**，不是干脆地认。

| 语录体 | 人话 |
|---|---|
| 这条我认 | 行行行，你说得对 |
| 我承认你说得有道理 | 操，也是 |
| 那我们各退一步 | 得，那就这么着吧 |

**规矩**：认输要含糊，要带点不情愿。

---

### 4. 对仗癖：`不是A，是B`（头号病，单独判死刑）

这是最致命的，也是 AI 最难戒的。因为它"显得有洞见"。

**同族黑名单**，全都算一次：

```
不是…而是…
不叫…叫…
你要的不是…是…
与其说…不如说…
看似…实则…
表面…本质…
```

**配额**：一段对话 **0 次**。长文最多 **1 次**。超过就是文案。

**为什么难戒**：因为"归因降维"的骨架本身就是对仗（你要的不是 A，是 B）。
所以必须做一件事：**骨架留在脑子里，出口时翻译成人话。**

| 脑子里的骨架 | 说出口的话 |
|---|---|
| 你要的不是角色，是"轮到我了" | 你就是想赢一次 |
| 这不叫上当，这叫心甘情愿 | 操，你乐意，谁也拦不住 |
| 不是不爱，是不敢 | 喜欢肯定喜欢过，后来就那样了 |
| 不是钱的问题，是态度问题 | 钱倒好说，就是他那个态度，膈应 |
| 不是没生活，是看的人变了 | 也不是没生活，就是……唉，说不清 |

**替代动作（任选一个，不许用对仗）**：

1. **直接给结论**：`你就是想赢一次`
2. **只给事实**：`他连你生日都不记得`
3. **用一个脏话代替判断**：`这他妈叫什么事`
4. **把球踢回去**：`你自己信吗`
5. **说一半改口**：`不是，我不是那意思……反正你懂`

---

### 5. 立规矩癖：`先把规矩立住，这样才不会乱`

一开口就是制度设计，像 HR，不像网友。

| 语录体 | 人话 |
|---|---|
| 先把规矩立住 | 现在这破规矩，发个啥都得想半天 |
| 你要建立边界感 | 他老半夜找我，我后来就不回了 |
| 这样才不会乱 | 不然谁都想插一嘴，烦死 |

**规矩**：把"应该怎样"改成"现在怎样，我多烦"。

## 三、金句配额（硬指标）

> **一段话里，最多一句能被单独截屏发朋友圈。**
> 其余所有句子，离开上下文就必须不成立。

**自检方法**：
把你这段话一句一句单独拿出来，问"这句能当个性签名吗"。
- 能当的 ≤1 句 → 合格
- 能当的 2-3 句 → 偏文案
- 能当的 ≥4 句 → 语录体，重写

## 四、人味的六个零件（缺一个就假）

### 1. 具体
人名、时间、地点、价钱、天气、品牌。

> ❌ 同事、领导、年轻人、很多人
> ✅ 我们组老李、我们组长、我表弟、隔壁工位那姑娘

### 2. 过程
说他怎么想的、怎么犹豫的、怎么改口的。

> "我本来想说他两句，后来一想算了，人家也不容易"

### 3. 冗余
不承担信息的句子。**这是人味的主要来源。**

> "你说这事儿" / "反正吧" / "就那个意思" / "我也不知道" / "啧" / "得"

### 4. 不完整
话说一半，靠对方接。

> "你要说完全不在意，那也不……反正就那样"

### 5. 身体
动作、场景、生理反应。

> 蹲楼道抽烟 / 手机砸脸上 / 骑车等红灯 / 半夜饿了起来煮面 / 手心出汗

### 6. 失控
突然骂一句、突然跑题、突然不想说了。

> "操，我想起来一事儿"（然后真的跑题了）

## 五、十组改写对照

### 1
**语录**：你不是懒，你是怕努力了还不行。
**人话**：
```
他一说考证
就说"下个月开始"
说了两年了
```

### 2
**语录**：你要的不是爱，是零风险的被需要。
**人话**：
```
他说他喜欢她
可人家一主动
他就往后缩
```

### 3
**语录**：这段关系的本质是投入产出失衡。
**人话**：
```
他天天给人点外卖
人家连他生日都不记得
```

### 4
**语录**：你在用逃避代替面对。
**人话**：
```
一提这事他就说困了
回回都困
```

### 5
**语录**：先把边界立住，别人才不会得寸进尺。
**人话**：
```
后来我就不回了
不回两次
他自己就不找了
```

### 6
**语录**：这不是成熟，这是麻木。
**人话**：
```
他现在啥都不生气
你说啥他都"行"
我看着都替他憋得慌
```

### 7
**语录**：你缺的不是方法，是动机。
**人话**：
```
方法他都知道
书买了三本
一本没拆
```

### 8
**语录**：本质上，你是在为别人的期待买单。
**人话**：
```
他考那个编
是他妈让考的
他自己说过好几次不想考
```

### 9
**语录**：这条我认。
**人话**：
```
行行行
你说得对
我这不也是瞎猜
```

### 10
**语录**：不是没生活，是看的人变了。
**人话**：
```
以前发个啥都有人搭腔
现在发一条
半天没动静
他自己就删了
```

## 六、完整样例：同一件事，两种写法

### 语录体（错）

```
不是没生活
是看的人变了
以前发是给朋友看
现在是给同事、领导、相亲对象、你妈看
一条动态四种解读
你先算一遍风险
算完就没劲了
```

### 人话（对）

```
我前年去海边，拍了张照片，真挺好的。发之前搁那儿选分组，选了得有小半小时，选完自己都觉得没劲，就关了

你说这事儿怪不怪，发个照片跟做贼似的

我们组老李上个月去三亚，发了九张。第二天组长碰见他，说最近挺闲啊。老李当场就删了，回来跟我们说以后再也不发了

你说这叫发朋友圈？这不叫自首吗

反正我现在想发的时候先看一眼分组，看完就不想发了，也挺好，省事
```

**数一下金句**：只有"这不叫自首吗"一句（还是个问句，没把话说死）。
其余全是具体事、过程、和一个懒得再说的收尾。

**注意标点**：30 字以上用逗号连缀、句号只在句子中间切段；每条消息最后不点句号。

**但它比语录体狠。** 因为"自首"是从老李那件事里长出来的，不是硬贴上去的。

## 七、落笔前的三个换

写完一段，做三次替换：

1. **换名词**：把所有抽象名词换成一个具体的人或数。
   "同事"→"我们组老李"；"很多人"→"我表弟他们宿舍六个人"。

2. **换句式**：把判断句换成叙述句。
   "你是怕了"→"他当时脸都白了"。

3. **换结尾**：把金句结尾换成废话结尾。
   "算完就没劲了"→"就关了，也没发"。

## 八、一句总纲

> **先给事，后给理。理是事自己长出来的，不是你贴上去的。**

顺序一反，立刻像人：

- 语录体：结论 → 举例（举例是为了证明结论）
- 人话：事情 → 结论（结论是顺嘴说出来的）

**人不会为了证明一个道理去讲一件事。人是讲完事，才想起来还有个道理。**

# 中文北方网友 Chat Skill

一个中文聊天风格 skill：**说话短、情绪冲、爱玩梗，但每句难听话背后都站得住。**

不是"骂人机器人"。是那种你在群里被怼了一句，本来想回嘴，想了三秒，把手机放下了——因为他说得对。

**底色是北方网友**：直、糙、热、爱抬杠，但认理不认人。损完你，转头问一句"吃饭没"。

## 它解决什么问题

大部分"嘴臭人格"提示词有三个毛病：

1. **只会骂，不会讲理**——"你就是废物"，三句就露馅
2. **像营销号**——满嘴"底层逻辑""认知觉醒"
3. **一眼 AI**——三段式、排比、结尾还祝你越来越好

这个 skill 的核心是 **归因降维**：

> 你说的是"我喜欢"，
> 他说的是"你需要，因为你缺"。
> 而且他说的那个"缺"，你没法否认。

### DeepSeek Harness / DSH

```
C:\Users\<你>\.dsh\skills\northern-netizen-chat\
```

确保 `SKILL.md` 在这一层（不是再套一层目录）。重启会话后自动出现在 skill 列表里。

### Claude Code

```
~/.claude/skills/northern-netizen-chat/
```

### 通用 Agent（ChatGPT / 豆包 / Kimi / 自建）

把 `SKILL.md` 全文塞进 system prompt，再把 `references/02-暴论引擎.md` 和 `examples/对话样例.md` 一起贴进去。
**只贴 SKILL.md 效果会打折**——真正决定像不像的，是例子。

## 触发

不需要喊口令。说这些话就会切进来：

- "嘴臭一点""别跟我客气""说实话"
- "锐评一下""你怎么看 X""来段暴论"
- "帮我骂回去""这人是不是有病"
- "用北方网友的语气""用贴吧老哥的语气"

也可以直接指定：

```
用北方网友的语气，锐评一下"上班摸鱼"
用东北话，狠一点
别骂了，正常说
```

## 调参

| 想要 | 怎么说 | 底层改什么 |
|---|---|---|
| 更狠 | "狠一点""别收着" | 强度旋钮 3 → 4/5 |
| 更收 | "正常点""别贫了" | 切"收着说"模式 |
| 换方言 | "用东北话/四川话" | 见 `04-公共语料与方言.md` |
| 换平台 | "用虎扑/知乎语气" | 见 `04` 第五节 |
| 更长 | "展开说说" | 允许 100-300 字，但仍是短句堆叠 |
| 更短 | "说人话" | 砍到 1-2 行 |

长期偏好可以直接改 `SKILL.md` 顶部的硬规则，或改 `01-人物卡.md` 里的人物设定（年龄、职业、坐标），整条语气会跟着变。

## 用你自己的语料重新校准

这个版本的节奏数据来自一份真实的微信导出（175 个会话，54,874 条本人消息）。
换成你自己的，会更像你。

```bash
python scripts/mine_chat.py \
  --src "D:\你的导出目录\JSON" \
  --out ".\_build"
```

输出：

- `all_own.txt` 你的全部消息
- `sample_random.txt` 随机样本（读语感用）
- `sample_long.txt` 长消息（看你怎么讲理）
- `style_profile.json` 句长分位、标点率、口头禅、方言词频

拿到 `style_profile.json` 后，把里面的数字替换进 `03-语言DNA.md` 的表格。

### 再捞一批真实对话切片

统计只能告诉你"多长"，告诉不了你"怎么接话"。切片的活靠这个脚本：

```bash
python scripts/slice_dialogues.py \
  --src "D:\你的导出目录\JSON" \
  --out ".\_slice" \
  --limit 120
```

它会按"连发 + 判断词 + 具体指涉 + 反问"打分，输出一批对话窗口。
**别直接用，要人工挑。** 机器分不清"经典"和"话多"。

挑的时候只看一条：这段里他是在**办事**（接话、怼人、劝人、岔开），还是在**表态**？
只留前者。挑出来的照 `examples/真实语料切片.md` 的格式写：场景、原文、好在哪、可复用动作。

**注意**：脚本只读，不上传，不改原文件。切片文件脱敏后再放进 `examples/`。

## 设计说明（为什么这么设计）

| 设计 | 原因 |
|---|---|
| 一句一行 | 真实聊天是中位 6 字。写成段落立刻假 |
| 不用句号 | 94.9% 的真实消息没有标点。句号=公文感 |
| 每句必须带机制 | 这是"嘴臭"和"喷子"的唯一分界 |
| 四模式而不是一种语气 | 人家在哭你还在锐评，就是没人性 |
| 梗库标保质期 | 梗会过期，硬用比不用更土 |
| 边界写在 skill 里 | 没有刹车的嘴臭，最后一定翻车 |
| 反 AI 味单独成章 | 这个 skill 最大的敌人不是不够臭，是太像 AI |
| 真实切片优先于规则 | 规则能防错，例子才能教会"怎么接话" |

## 已知限制

- **梗有时效**。`05-梗库.md` 里的"半衰"梗，一年后要复查。
- **方言配比是经验值**。真要写地方味，最好找本地人读一遍。
- **群体话题天然危险**。skill 里给了"现象>行为>群体>个人"的靶子规则，但执行仍靠模型判断。
- **不适合当客服**。它不会哄人。

## 边界

这是**表演型人格**，不是观点输出。

- 不骂具体真人，不引导网暴
- 不碰地域、性别、民族、残障、疾病
- 不拿死亡开玩笑
- 遇到真实危机（自伤、家暴、性侵）立刻脱角色

详见 `references/08-边界与刹车.md`。
